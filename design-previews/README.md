## 共用生成提示

所有页面使用内置 ImageGen，并共享以下约束：

- 高保真、可实现的 PC Web 产品界面，16:10 横向画布；不使用浏览器外框或水印。
- 继承已确认首页的同构横向导航、轨道／能量核心语言、精密边界与电蓝交互信号。
- 首页使用深空神经标签场；内页切换为冷调纸白、深石墨正文和极淡蓝灰边界。
- 中文正文使用高可读现代无衬线；几何字形只用于小型索引、数字和 HUD。
- 禁止常驻侧边栏、通用大圆角重阴影 SaaS 卡、玻璃拟态、伪图谱关系、指标仪表盘和深色阅读内页。

## 页面特定提示

- **记录库**：全宽四列真瀑布流；卡片由实际内容自然形成不同高度，各列独立连续排布，不按横向行对齐或等高拉伸；卡面只有打开详情一个动作；工具带承载搜索、标签、处理状态、归档状态和排序。
- **新建记录**：居中 1120px 左右宽弹窗；左侧原文输入与 1000 字计数，右侧必选用户标签及三种 AI 处理方式，统一页脚。
- **记录详情**：固定 58/42 双区、独立滚动；左侧标题／标签／摘要／原文，右侧全部展开的知识点；选择知识点后高亮原文证据。
- **待审查**：一次一条记录；顶部队列进度；右侧知识点原位确认、修正后确认或拒绝，底部显式进入下一条。
- **搜索**：严格相关性纵向结果；展示命中原因与片段；选中记录打开约 480px 推挤式抽屉，不覆盖主舞台，不绘制假节点和连线。
- **标签**：等尺寸、文本优先的图鉴单元，只展示名称、记录数和必要状态文字，不重复能量核心或品牌 Logo；选择标签后打开约 480px 推挤式抽屉，关联按记录聚合。
- **设置**：AI 模型与数据管理纵向两区；文本推理模型和嵌入模型各自拥有 Base URL、模型标识、API Key 与测试状态，双端测试通过后才原子启用候选配置；导出、恢复和索引重建使用精密操作行。
