# 可爱马卡龙 UI 概念稿

> 生成日期：2026-08-10
> 状态：方向选择稿，尚未进入正式 UI 实现。

三稿共享同一视觉世界：糖果标本柜 × 手帐文具。奶油纸白与草莓粉构成主场，淡紫、开心果绿、香草黄和天空蓝承担标签身份；深莓果色用于正文，保证可读性。标签间不绘制关系线，避免在 V1 暗示不存在的知识关系。

## 方案 A：马卡龙标本花园

文件：`01-macaron-constellation-garden.png`

- 保留首页当前自由探索的空间感，以马卡龙大小、远近和散落位置建立层次。
- 视觉冲击最强，最贴近原首页“标签场”的功能。
- 风险是实物甜点质感偏强，正式实现需要收敛装饰并避免像食品展示页。

## 方案 B：贴纸活页图鉴

文件：`02-sticker-binder-atlas.png`

- 用活页、标签页和透明资料袋表达原文、AI 整理和证据链的长期并存。
- 最能贯穿首页、记录库、详情和审查页，产品隐喻完整。
- 风险是具象手帐占用空间较多，密集工作页需要切换为更平面的纸张语言。

## 方案 C：糖果标本抽屉

文件：`03-candy-specimen-drawer.png`

- 用独立格位与抽屉表达标签检索和记录展开，选中后的信息层级最清楚。
- 操作效率高，适合把首页探索与记录预览合在同一视口。
- 风险是固定格位容易让人误解为分类关系，正式实现需明确这只是视觉陈列。

## 下一步

选定一稿或指定混合方式后，再更新 `DESIGN.md`、建立正式 token，并以语义化 HTML/CSS 与有限 3D/SVG 重建界面。概念图中的文字排版和实物细节是视觉北极星，不会作为位图直接嵌入产品 UI。

## 第二轮：可扩展气泡图谱

第一轮反馈指出，具象马卡龙无法承载大量标签、纯 CSS 难以稳定复刻，翻页与固定格位也不利于查找和未来图谱演进。第二轮因此不再把“马卡龙”当作实物，而只保留它的粉嫩配色与软润轮廓。

三个文件展示同一套节点系统的关键状态，而不是三套彼此竞争的物件隐喻：

- `04-scalable-bubble-atlas-overview.png`：高密度总览。远景节点按 LOD 退化成小点，近景和焦点节点才显示标签。
- `05-scalable-bubble-atlas-search-focus.png`：搜索聚焦。匹配项临时放大，其他标签继续保留为空间背景，不需要翻页。
- `06-scalable-bubble-atlas-selected-tag.png`：选中详情。右侧记录面板推挤画布，标签场仍是主导航模型。

节点只依赖纯色圆、内圈、1px 描边和偏移阴影，可以由 WebGL、SVG 或 CSS 原语一致实现。MVP 不绘制关系边；未来只需在同一坐标系下增加边图层，不必替换节点或交互模型。
