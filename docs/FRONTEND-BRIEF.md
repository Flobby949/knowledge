# V1 前端设计基线

> 状态：已确认  
> 日期：2026-08-10
> 需求事实以 [PRD](../PRD.md)、[领域语言](../CONTEXT.md) 与 [ADR](./adr) 为准；本文用于快速建立一致的界面与交互心智，不替代验收条款。

## 1. 体验主张

产品只有一个用户一级对象：记录。界面不要求用户理解 Fragment、Knowledge Point 或 Revision；内部版本、证据与发布状态只在核验和管理时以用户语言呈现。

V1 提供两套完整且可持久化的视觉环境。默认马卡龙主题：首页是可缩放的彩色气泡标签场，内页使用云朵纸白、深莓果正文与花瓣边界。科幻主题：首页恢复深空神经信号场，内页切换为冷调纸白、蓝灰结构和电蓝操作信号。两套主题共享内容、布局、交互、状态与可访问语义。

可爱感来自马卡龙色彩、圆形节点、友好比例与克制运动，不依赖真实甜点、手帐或抽屉等难以扩展的物件，也不牺牲工作台密度。

## 2. 交付边界

- 只交付 PC Web；V1 不设计或验收移动 Web、原生移动端和原生桌面端。
- 最低验收宽度为 1280 CSS px，主要优化 1440–1920px。
- 正式支持当前稳定版 Chrome 与 Edge，3D 以 WebGL2 为基线；Firefox 与 Safari 尽力兼容。
- 不设置常驻或可折叠侧边栏，不提供应用级全局快捷键。主题由用户明确选择，不跟随系统明暗模式自动改变。
- WebGL2 不可用时，首页降级为仍可搜索、定位和点击全部标签的主题等价 2D 场；其他功能不受影响。

## 3. 视觉系统

### 3.1 色彩

- 马卡龙首页：云朵纸白背景与深莓果文字；节点使用草莓粉、淡紫、开心果绿、香草黄和天空蓝。
- 科幻首页：深空黑背景、冷白文字与青蓝／紫色膜状节点；内页使用冷调纸白、蓝灰边界与电蓝信号。
- 标签色相由稳定身份生成，跨访问保持一致，但不表达分类、关系、热度或认可状态。
- 内页：云朵纸白、深莓果正文、花瓣粉边界；深草莓色用于主操作、焦点与选中态。
- 不在同一页面混用两套主题语法；科幻辉光只服务节点、焦点和真实动态反馈，不扩散为全页持续闪烁。

### 3.2 字体与形态

- 中文标题、原文、摘要和知识点使用高可读现代无衬线。
- 几何字体只用于 HUD、数字、索引和短英文技术词；长文不使用展示体或等宽字体。
- 记录使用纯白内容卡：细花瓣边界、8–12px 圆角、近乎无阴影，悬停仅轻抬并增强边界。
- 内页空状态使用小型同心气泡，配一句具体说明和至多一个主操作。

### 3.3 顶部导航

导航常驻品牌/首页、记录、待审查、标签、全局搜索、新建记录、主题快捷切换和设置，不放头像、账户菜单或通用通知中心。导航随主题切换为马卡龙白色或科幻深色首页／冷调内页语法。

仅当存在处理中或失败的 AI 任务时显示任务脉冲；浮层可打开相关记录或重试失败任务，空闲时隐藏。

## 4. 首页：双主题 3D 标签场

- 顶部导航以下占满首屏，不放统计卡、最近记录、待审查面板、中央展框或左右分屏。
- 马卡龙主题的 Tag 是纯色圆、奶白内圈、细描边和轻偏移阴影；科幻主题恢复不规则膜状轮廓、同心信号层和端口。已认可标签使用完整外圈，AI 候选使用虚线外圈并明确标注状态。
- 节点在完整 3D 空间无语义乱序分布，稳定坐标不因访问、旋转或新增标签重排；尺寸只表示关联的去重有效记录数，不决定中心位置。
- 所有现存标签节点始终在场。名称贴近球体并始终朝向镜头，按屏幕宽度单行省略；远处或发生碰撞的名称可渐隐，靠近、悬停、聚焦或搜索定位后恢复。
- 聚焦节点时增加双层草莓色焦点环、轻微降低其他节点亮度，并显示完整名称、记录数和认可状态；点击直接进入 Tag 硬筛选搜索。
- 马卡龙主题不绘制装饰关系线；科幻主题保留的动态信号线必须明确标注为视觉环境，不表示标签关系。未来真实图谱在同一坐标系下增加独立关系层。
- 拖拽旋转，滚轮或触控板缩放，有安全上下限和重置视角；返回首页时恢复旋转与缩放。
- 搜索 HUD 键入时即时匹配标签；按 Enter 或明确提交后才执行记录关键词/语义搜索。
- 0–300 个标签保持完整画质；301–1000 个通过 LOD 隐藏非焦点文字、缩小节点和减少背景粒子，但保留全部节点。1000 是验收规模，不是数据硬限制。
- 全新实例只显示“第一颗知识节点”引导，不伪造示例标签。

## 5. 新建与编辑记录

- 全局新建使用居中宽版弹窗，不跳转页面，也不打开侧边抽屉。
- PC 内部约 64% / 36%：左侧是原样纯文本输入、校验和 1000 字计数；右侧是“我的标签”和 AI 处理方式；底部统一取消与保存。
- 三种处理方式使用纵向紧凑单选卡：仅保存、AI 整理并自动采用、AI 整理后由我确认。模型不可用时两张 AI 卡保留但禁用。
- 每条记录保存后必须至少有一个记录级“我的标签”。编辑中可暂时删除最后一个标签，但最终为空时保存禁用；AI 候选不计入。
- 编辑记录复用同一弹窗。只改标签时不创建 Fragment Revision 或 AI 任务；原文变化时才启用处理方式并创建新版本；没有变化时不能提交。
- 保存成功后关闭弹窗并停留原页面，以非阻塞提示区分已保存与 AI 处理中，并提供查看记录入口。脏弹窗关闭前确认放弃，V1 不保存草稿。

## 6. 记录库

- 全宽、多列、响应式真瀑布流，使用由实际标题、预览和标签换行自然形成的不同高度档案卡；各列独立连续向下排布，禁止按横向行对齐、等高拉伸或用空白补齐短卡；不使用表格、固定行或主从分栏。
- 卡片展示当前有效内容：有生效 AI 整理时使用有效标题与摘要，否则使用原文首个非空行和原文片段；状态使用用户语言。
- 整张卡只有打开详情一个动作，卡面不提供编辑、归档、重新整理或更多菜单。
- 顶部使用轻薄可吸顶工具带，承载页内搜索、标签、处理状态、归档状态和排序；启用条件可逐个移除或全部清除。
- 使用稳定游标无限滚动和离屏虚拟化；从详情返回时恢复条件、已加载范围与精确滚动位置。

## 7. 记录详情与版本

- 顶部导航下占满可用区域，左侧约 58% 展示标题、有效标签、整体摘要和完整原文，右侧约 42% 展示全部当前知识点；两侧独立滚动，不提供拖拽调宽。
- 右侧 1–5 个知识点全部展开，显示完整标题、正文、AI 标签和证据数量。选择知识点后，左侧定位并高亮其全部 Evidence Span。
- 知识点引用旧原文时，原文块切到真实历史版本并持续显示版本落后提示；标题、标签和当前摘要不回退，可返回当前原文或整理最新原文。
- 知识点修正使用居中宽版弹窗；保存后标记用户修正，保留 AI 原值入口，并明确证据只对应 AI 原始内容。
- 每个知识块底部直接提供修正和暂不采用。暂不采用立即移入折叠历史区并提供撤销，不弹确认框。
- 顶部吸顶操作条提供返回、状态、编辑记录、重新整理和历史版本；归档/恢复与永久删除进入更多菜单，永久删除独立危险分组并二次确认。
- 历史版本打开临时全屏工作台：顶部横向时间轴，下方查看快照或与当前版本对照；关闭后恢复双区滚动、选中知识点和证据高亮。

## 8. 待审查

- 一次审查一条记录，顶部展示队列进度与前后切换，主体复用详情双区和证据联动。
- 首次 AI 整理中，每个知识点原位提供确认、修正后确认和拒绝；处理后留在原位显示结果。全部完成后由用户显式“完成并下一条”，不自动跳转。
- 提供当前记录“全部确认”与“保留未处理并下一条”；后者不隐式处理知识点。
- 编辑原文后的新分析和 Reanalysis 保持左侧原文、右侧当前/候选版本对照，标出新增、删除、修改、拆分、合并和标签变化；只允许整版采用或丢弃。

## 9. 搜索与未来图谱接口

- V1 使用“搜索舞台 + 选中对象 + 右侧知识抽屉”。主舞台严格按相关性纵向展示 Record 聚合结果，不画无真实关系的节点云或连线。
- 结果块展示标题、摘要、命中标签、一个或多个高亮片段，以及命中原文、命中知识点或语义相关等原因。
- 点击结果后右侧约 480px 抽屉推挤主舞台；不覆盖、不加遮罩、不允许拖拽调宽。抽屉展示有效记录信息、命中知识点和原文片段，并可打开完整详情。
- 选中 Record 写入 URL；浏览器返回优先关闭抽屉并恢复结果位置。
- 查询提交后形成稳定相关性快照，以游标无限滚动加载；后台更新和抽屉开合不重排当前结果，重新提交才刷新排名。
- V3 只替换主舞台渲染器为真实图谱；选中状态、URL、知识抽屉和完整详情入口继续复用。抽屉开合只改变图谱视口，不重算稳定节点布局。

## 10. 标签

- 顶部切换“我的标签 / AI 候选”，并提供搜索与排序；主体使用等尺寸标签图鉴，不重复首页标签云。
- 每个图鉴单元以名称与去重记录数为主体；AI 候选按需显示明确状态文字。卡面不重复能量核心、品牌 Logo、轨道球体或管理按钮。
- 点击后复用推挤式右侧抽屉。关联按 Record 聚合，同一记录只出现一次；展开后查看具体 AI 知识点并逐条屏蔽或恢复，不暴露 Tag Assignment 等内部对象。
- 抽屉承载候选升级、允许的候选删除与已认可标签改名等操作。候选升级复用同一 Tag 身份及全部历史关联。

## 11. 设置

- 单页工作台纵向排列外观主题、AI 模型和数据管理三个精密面板，顶部横向锚点跳转；不使用设置侧栏或互斥标签页。
- 外观面板提供马卡龙气泡与科幻信号场两个明确预览。切换即时作用于全部页面并写入浏览器本地存储；顶栏提供同一动作的快捷入口，刷新不得闪回默认主题。
- 模型面板区分当前生效配置与候选草稿，并在两部分内分别设置“文本推理模型”和“嵌入模型”配置组；两组各自具有 Base URL、模型标识、API Key 和独立测试状态，不共享连接字段。两项测试全部通过后才可原子启用整套候选配置；任一字段变化使对应测试失效，失败不覆盖当前配置，凭据不回显。
- 数据面板承载完整 ZIP 导出、空实例恢复及全文/向量索引重建进度；恢复不可用时直接说明原因。

## 12. 通用状态与可访问性

- 核心交互遵循标准 Tab 顺序、清晰焦点、Enter/Space 激活、适用控件的方向键以及 Esc 关闭当前临时层；不提供应用级全局快捷键。
- 系统减少动态效果偏好关闭自动旋转、气泡呼吸和科幻信号脉冲；任何状态都不能只用颜色表达。
- 异步处理中使用局部状态和顶部任务脉冲，不让用户等待空白页面；失败必须保留原文并提供明确重试路径。
- 弹窗、抽屉、全屏工作台和浏览器返回都必须恢复来源页面的选中、筛选、滚动与镜头状态。

## 13. 明确不做

- 移动端适配、登录与多用户、常驻侧边栏、全局快捷键、跟随系统自动主题。
- V1 Concept、真实关系图、标签共现图、伪造关系线或图数据库。
- 首页统计仪表盘、记录列表或默认录入页。
- 记录库表格、卡片快捷操作、搜索结果瀑布流。
- 两套主题的视觉混搭、高饱和赛博朋克、黑金宇宙、真实甜点／手帐隐喻、通用大圆角重阴影 SaaS 卡片。
