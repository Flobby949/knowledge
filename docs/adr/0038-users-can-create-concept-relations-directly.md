# Concept Relation 支持用户直接建立

ADR-0034 固定了 V3.2 的首版入口：AI 先提出 Suggestion，用户确认后才形成正式 Concept Relation。真实使用表明这条入口不足以表达用户已经知道存在、但模型没有召回或没有提出的 Concept 联系，因此正式关系现在同时支持“AI Suggestion 经用户确认”和“用户直接建立”两种确认来源。直接建立必须由用户选择另一个当前有效 Concept、六种既有关系类型、规范方向和非空描述；它不调用模型、不引用模型配置，也不伪造 Suggestion。正式 Concept Relation 自身冻结两端当时的 Concept Revision 与有效 Membership 指纹，两种来源都使用同一套不可变身份、同型去重、对称端点规范化、`needsReview`、默认网络过滤和只记录撤销的历史规则。这个决定只取代 ADR-0034 中“不提供用户直接创建”的范围限制，不改变 AI 不得自动写正式边、六型关系语义或人工决定门。

本决定的用户直接创建入口已由 ADR-0039 取代。既有 `USER` 来源关系仍保留其真实来源且不得伪造模型信息，但当前产品不再提供新的人工创建界面或写接口。
