# 文本推理与 Embedding 模型使用独立端点

V1 仍只维护一套供全部记录和后台任务共用的实例模型配置，但这套配置由两个独立的 OpenAI-compatible 端点组成：文本推理端点和 Embedding 端点分别保存自己的 Base URL、服务端凭据与模型标识，可以指向不同厂商或部署。我们不再要求两类模型共享服务地址，因为文本生成与向量服务在实际部署中经常来自不同提供方；同时仍不引入多配置档案或逐记录模型选择。

候选配置必须分别测试两个端点，并在两项测试都绑定当前候选快照且通过后原子启用整套配置；系统不能只发布其中一个端点。修改文本推理端点不会改写历史分析，修改生效 Embedding 端点的 Base URL 或模型标识则触发全量向量重建，避免把不同向量空间混合检索。该决策取代 ADR-0020 中“一个服务地址承载两类模型”的部分，其余单实例、凭据不回显和历史可追溯约束继续保留。
