# 知识关系必须人工确认并保留端点历史

V2 先用当前生效 Knowledge Point 的 Embedding 召回候选，再让文本模型提出预设关系类型、描述、理由、置信度和两侧 Evidence Span；这些结果只作为绑定确切知识点内容指纹的 Relation Suggestion，用户可以修改类型或描述后确认、拒绝，确认后才另建 Knowledge Relation。重新分析、知识点退出生效或模型再次扫描都不得覆盖或删除已确认关系，只能把端点变化标记为需要复核；撤销关系也仅写入结束时间。这样能让正式关系始终来自明确的人类决定并保留完整端点来源，代价是建议与正式关系需要独立状态和审查界面，且 V2 不把关系自动提升为 Concept 或图谱结构。
