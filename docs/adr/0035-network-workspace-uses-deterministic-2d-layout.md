# 功能性知识网络使用确定性 2D 布局与等价列表

V3.3 新增独立 `/network` 工作区，不替换首页或搜索页。初始图以当前有效 Concept 为主，只有选择、节点搜索、路径或局部展开需要时才加载 Knowledge Point；客户端只绘制网络 API 返回的 `concept_membership`、`knowledge_relation`、`concept_relation` 三类真实边，路径也只高亮服务端返回的有序边，不根据视觉距离、相似度或客户端遍历补全连通性。

2D 坐标是版本化的客户端派生布局快照，不进入数据库或网络 API。布局输入先按 typed node key 和真实 edge key 排序，以确定性算法产生同一拓扑可复现的坐标；筛选、搜索、路径高亮和 480px 推挤式详情抽屉只改变可见性或视口，不重算坐标。局部展开可以为新节点计算位置，但冻结全部既有节点坐标。该决定避免持久化纯表现数据，也禁止复用首页 Tag 场无关系语义的位置。

已提交交互状态由 URL 中的 `node`、`from`、`to`、`q`、重复 `type`、重复 `relation` 和 `view=graph|list` 表达，坐标、缩放与摄像机不写入 URL。SVG 与键盘等价列表共享同一状态；SVG、布局 Worker 或运行时渲染失败时保留 URL、筛选、选择和路径并自动切换到列表。V3.3 的 2D typed-key、真实边、URL、选择、路径、详情和降级合同是 V3.4 3D 表现层的正典，3D 不得重新定义网络语义。
