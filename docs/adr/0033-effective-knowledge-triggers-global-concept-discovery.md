# 生效知识自动触发全局 Concept 发现

V3.1 不再要求用户选择 Concept Candidate Scan 的输入范围。每个 AI Analysis Revision 首次成为当前生效分析时，系统在同一业务事务中登记一次持久化发现任务，以该分析的有效 Knowledge Point 为种子，等待当前 Embedding 就绪后从全局当前生效且未排除的知识点中按语义相似度补充召回，并冻结最多 12 个输入；仅保存的 Fragment 仍参与全局原文检索，但不会登记发现任务，Mode B 待审查、全部拒绝或丢弃也不会触发。单一输入且没有召回结果时直接记录无建议，多个输入才交给文本模型生成至多一个 Candidate。系统只在知识生效事件后增量发现，不定时扫描全库，也不为升级前的历史分析自动回填任务，避免部署后产生不可预期的模型成本。Candidate 仍必须由用户确认后才能创建 Concept 与 Membership；自动化止于候选发现，不扩展为自动归属或自动建图。本决定取代 ADR-0032 关于主动选择扫描范围的部分。
