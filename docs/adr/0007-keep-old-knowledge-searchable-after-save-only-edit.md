# 仅保存新原文后旧知识继续参与搜索

已有生效知识的 Fragment 保存新原文版本并选择“仅保存”时，旧 AI 分析继续保持 `ACTIVE`，知识点继续关联同一个 Fragment，并与其他生效知识点使用相同的搜索召回、过滤和排序规则。知识点始终引用实际生成它的 Fragment Revision；它是否落后于 Fragment 当前版本由引用关系直接推导，不新增生命周期状态或搜索分支。搜索结果只用“基于 vN，当前 vM”一类轻量文字呈现版本差异，不使用警告样式。我们接受知识可能暂时滞后的风险，以避免仅保存操作使已有知识突然消失，并保持搜索模型简单一致。
