# V1 使用一套实例级模型配置

V1 只维护一套供全部记录与后台任务共用的 OpenAI-compatible 配置，包括服务地址、服务端保存的可选凭据、一个 AI 整理模型标识和一个 Embedding 模型标识；不提供多配置档案或逐记录模型选择。每个 AI Analysis Revision 保存实际使用的模型标识和非敏感配置版本，任务开始后固定该版本，配置变化不会自动重新分析或改写历史结果。凭据不进入记录、分析、日志或完整导出包，保存后也不向客户端回显明文。

实例没有通过测试的有效配置时，保存界面强制采用“仅保存”并禁用 AI 整理，但记录保存和关键词搜索继续可用；系统不创建注定失败的任务，也不把配置缺失记录为 `PROCESSING_FAILED`。配置成功后，用户可以主动整理此前记录。若任务启动时配置有效、随后服务调用失败，则仍按正常处理失败与重试规则执行。

Embedding 模型变化时，现有向量不再与新向量处于同一可比空间。系统立即暂停语义搜索，不保留旧模型配置提供临时查询，也不逐步发布或混合新旧向量；关键词搜索保持可用。只有全部可检索语料的新向量通过完整性校验并一次性激活后，语义搜索才恢复。重建失败时继续暂停并允许重试，不发布部分索引。这个边界避免 V1 引入双模型路由与逐记录配置复杂度，同时保留替换服务和模型的能力。
