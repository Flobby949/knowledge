# Concept Candidate 冻结输入并由用户事务性晋级

V3.1 只允许用户从 2–12 个当前知识点主动发起 Concept Candidate Scan，每次扫描冻结有效标题、正文、证据、内容指纹和模型信息，文本模型最多提出一个不可变候选或无建议结果，绝不直接写入 Concept。用户只能在冻结输入范围内编辑名称、描述和至少两个成员后接受，接受操作在同一事务中创建 Concept、初始 Membership 和不可变审查决定；拒绝同样保留历史，任何输入表达或生效状态变化都会让候选过期并阻止接受，同一输入与候选指纹已经处理后也不重复提出。这样牺牲了静默聚类和全自动建图的速度，但保住了正式认知节点的人类确认、确切来源和可解释失败边界。
