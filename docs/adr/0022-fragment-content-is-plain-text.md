# Fragment 正文是原样纯文本

V1 把 Fragment Revision 正文保存为原样 Unicode 纯文本，保留换行和空白；Markdown 标记、HTML 标签、代码围栏等都作为普通字符安全显示，不解析、不渲染也不执行。产品不提供 Markdown 预览、富文本编辑器或隐藏格式结构。AI 整理、关键词索引、Embedding 和 Evidence Span 均以同一纯文本快照为依据，从而保持原文不可变和证据偏移可复现。

正文的 1000 字上限按 Unicode 扩展字素簇（用户感知字符）计算。一个完整 Emoji 或组合字符算 1 个字符，每个空格、Tab 和换行分别算 1 个，首尾空白也计入。字符计数只用于校验，不对原始字符串执行规范化、截断或其他改写。

空字符串或只包含 Unicode 空白的字符串不能创建 Fragment Revision，首次创建和原文修改都必须至少包含一个非空白字符。该检查不执行 `trim`：只要正文有效，首尾空白仍属于不可变原文；已有记录也不能通过保存空版本代替永久删除。

完整导出的 JSON 保存原始字符串；人类可读 Markdown 必须通过转义或隔离方式嵌入正文，不能让用户正文改变导出文件结构。该决定牺牲富文本展示能力，以换取更简单的数据模型、安全渲染和稳定溯源。
