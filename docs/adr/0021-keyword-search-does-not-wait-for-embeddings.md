# 关键词搜索不等待 Embedding

Fragment、已发布 Knowledge Point 或用户修正一经生效就立即进入关键词搜索，对应搜索文档的 Embedding 异步生成；只有绑定当前内容版本和当前 Embedding 模型版本的 `READY` 向量参与语义召回。内容变化时旧向量立即失效，迟到任务只有在两个版本仍匹配时才能发布结果。Embedding 失败不会隐藏内容或回退使用旧内容向量，该文档继续参与关键词搜索并提供幂等重试。

单条文档的 `PENDING` 或 `FAILED` 只让它暂时缺席语义召回，其他 `READY` 文档继续提供语义搜索。该局部降级不同于 Embedding 模型变化后的全量重建；后者仍整体暂停语义搜索，直至完整新索引一次性激活。这个决策优先保证捕获与关键词检索即时可用，同时避免陈旧向量代表已经修改的知识。
