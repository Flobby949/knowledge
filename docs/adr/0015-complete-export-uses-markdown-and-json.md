# 完整导出同时使用 Markdown 和 JSON，并只恢复到空实例

V1 的完整导出是一个带格式版本号的 ZIP：每条未永久删除的记录具有便于脱离产品长期阅读的 Markdown，同时由机器可读 JSON 保存无损重建领域数据所需的全部对象、历史版本、稳定身份、状态与引用关系。Markdown 是阅读视图，JSON 是恢复所依据的结构化事实；Embedding、搜索索引、缓存、任务运行记录等可再生成数据，以及模型密钥、部署凭据和日志均不导出。

V1 同时支持把受支持版本的完整 ZIP 恢复到没有任何领域数据的空实例。系统必须先校验整包结构与引用完整性，再以全有或全无的方式写入；失败不能留下部分数据。恢复保留全部领域身份和历史引用，但不覆盖当前实例的模型密钥、部署凭据或运行配置，并在写入后重新生成派生索引。V1 不支持把导出包合并到已有数据中，因为身份冲突、同名标签、版本历史与用户修正的合并规则会显著扩大范围。该决策同时保护长期可读性与实际可恢复性，代价是产品需要维护 JSON 模式版本兼容并明确限制恢复目标。
