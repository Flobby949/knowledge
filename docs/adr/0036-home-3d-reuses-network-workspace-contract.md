# 首页真实 3D 网络复用功能性网络合同

V3.4 选择首页作为第一个真实 3D 知识网络主舞台，搜索页继续保留稳定相关性结果，独立 `/network` 工作区继续作为正典 2D 视图与降级入口。3D 只增加表现层：它复用 V3.3 的 typed node key、三类真实边、节点选择、URL、路径、480px 详情抽屉和键盘等价列表，不产生新的节点、边、路径或关系语义。

3D 与 2D 共享同一份版本化、确定性的 V3.3 布局快照；3D 原样使用其 x/y，并仅按 typed node key 派生稳定、浅层且有界的 z。z 不持久化、不进入 API 或 URL，也不表示关系类型、强弱、相似度、层级或中心性；局部展开冻结已有节点的 x/y/z。初始舞台只加载当前有效 Concept，选择、节点搜索、路径或局部展开需要时才加入 Knowledge Point。

首页底部既有 Tag 定位／记录搜索和全局新建记录入口继续保留，但 Tag 不进入真实知识网络。WebGL2 不可用、初始化或帧渲染异常、上下文不可恢复丢失时，首页保留全部网络查询、URL、选择、路径和抽屉状态并降级到 V3.3 2D；2D 渲染再失败时进入同状态的键盘列表。减少动态效果偏好下 3D 使用按需单帧刷新，不运行持续 `requestAnimationFrame` 循环。

首页真实网络不得改名复用旧 Tag 场的随机位置、虚假装饰连线、按关联记录数缩放、`USER_APPROVED`／`CANDIDATE` 外圈或其他 Tag 状态语义。正式压力验收使用合成的 500 个节点与 1000 条真实边，不改变线上网络 API 的 300 节点／600 边上限；正式浏览器、视口、帧时间、布局、首次可交互和内存预算由 V3.4 路线与 PRD 固定。
