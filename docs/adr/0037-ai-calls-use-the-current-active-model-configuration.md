# AI 调用使用当前生效模型配置

实例仍只有一套生效模型配置；队列任务、冻结输入和历史结果不拥有可继续执行的旧端点。每次文本或 Embedding 调用开始前都选择当时的 `ACTIVE` 配置，排队期间配置变化或失败后重试都使用最新生效的 Base URL、凭据和模型，任务、扫描及结果只记录本次实际使用的非敏感配置版本与模型名。已经发出的单次请求不会在途中切换配置，Embedding 迟到结果仍必须通过当前配置校验才能发布。

这项决定取代 ADR-0020 中“任务开始后固定旧配置版本”及 ADR-0032 中冻结模型配置的部分；领域输入快照、不可变 AI 结果和人工确认历史继续保留。失败的自动 Concept Candidate Scan 不算发现覆盖，用户显式执行全量发现时可按当前生效配置重新排队，但成功结果和正在处理的任务不会因配置变化自动重算。
