# 归档可恢复，永久删除不可恢复

V1 将归档作为日常可恢复操作，并提供独立、二次确认的永久删除。永久删除会级联清除记录的所有 Fragment Revision、AI Analysis Revision、Knowledge Point、Evidence Span、用户修正和 Tag Assignment，取消未完成 AI 任务并拒绝迟到结果回写；系统不增加 30 天回收站状态。这个设计以更简单的生命周期同时满足误操作恢复和私人知识彻底删除，但要求永久删除在界面和并发控制上保持明确且不可误触。

记录存在任何未结束 AI 任务时禁止归档，任务成功、失败、服务端超时或系统终止后才重新开放归档入口；系统不让后台处理穿越归档边界。V1 不提供用户手动取消 AI 任务的入口，每次模型调用必须有有限的服务端超时，避免记录永久停留在处理中。归档操作必须原子检查任务状态，避免检查与新任务创建竞态。永久删除仍可在处理期间执行，因为它会强制取消任务并通过删除标记拒绝迟到回写。
